# 🔢 Number Pattern Generator

A simple Python project that generates different number patterns based on the user's choice.

## 📌 Features

* Enter the number of rows.
* Choose from two different patterns:

  * Increasing Number Pattern
  * Repeated Number Pattern
* Allows the user to generate another pattern.
* Simple menu-driven program.
* Beginner-friendly Python project.

## 🛠️ Technologies Used

* Python

## ▶️ How to Run

1. Make sure Python is installed on your computer.
2. Download or clone this repository.
3. Open the project folder in Command Prompt or VS Code.
4. Run the following command:

```bash
python "Number Pattern Generator.py"
```

## 📖 How It Works

### 1. Increasing Number Pattern

If you enter `5`, the output will be:

```text
1
12
123
1234
12345
```

### 2. Repeated Number Pattern

If you enter `5`, the output will be:

```text
1
22
333
4444
55555
```
